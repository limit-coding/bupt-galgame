REFERENCE / ACCURACY

让每一处还原都有依据。

这是一份可继续迭代的游戏场景初稿。建筑位置根据 2026.08 校园示意图人工定位，以约 500 × 750 米的校园范围换算；地图本身并非测绘底图。

  • 有依据：主要建筑名称、分区与相对位置；六处地标的正面外观特征。
  • 估算：楼高、建筑占地尺度、道路宽度与背面细节。
  • 季节：四季共用固定主体；植被配色、花瓣、落叶和薄雪为演示预设，不代表已核实的树种、日期或天气。
  • 占位：其余立面、家属区推演楼排与树木分布；尚未包含室内；角色、天空和可布置物件为原创演示内容。

操作

鼠标拖动旋转全景，滚轮缩放。漫游中用 WASD / 方向键移动，Shift 加速，空格跳跃，V 切换第一 / 第三人称，F 切换飞行 / 落地，E 查看地点，Esc 暂停。飞行中空格上升，Q / Ctrl 下降，按住画面拖动转向。触屏使用方向按钮移动，拖动画面转向。

“只看固定主体”便于核对建筑；关闭“风与飘落动画”可减少动态效果。
