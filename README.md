# 西土城四季 · 北邮校园漫游 2.0

一个可独立运行的风格化 3D 校园作品：以北京邮电大学海淀（西土城）校区为舞台，包含固定校园主体、四季与日夜、自由探索，以及从西门到运动场的九页校园手记。参考照片的季节色彩与光照没有烘焙进建筑贴图。

## 2.0：进入校园，而不只俯看地图

沿用 Three.js + Vite，在现有校区数据与四季系统上升级。默认提供三种入口：俯瞰校园、角色漫游、自由飞行。角色为原创简约学生形象，不使用《原神》或《我的世界》的游戏素材。

- **角色漫游**：第三人称跟随镜头、奔跑和跳跃；`V` 切换第一人称。角色沿地面移动，建筑和个人布置物件会阻挡行走，跟随镜头检测场景遮挡。
- **自由飞行**：`F` 起飞；WASD、空格上升、Q / Ctrl 下降、Shift 加速。按住画面拖动转向；可在 2–800 米高度范围观察屋顶。`F` 或“降落”会在附近搜索可行走空地；没有安全落点时保留飞行。
- **场景布置**：飞行工具栏选择树、长椅或石块，点击地面放置，`R` 旋转。可移除自己添加的物件、撤销最近 40 次操作、导出 JSON。最多 160 件，自动保存于当前浏览器与端口，保存失败会提示仅本次会话。布置层不修改校园建筑；不提供建筑拆除、体素地形或 JSON 导入。
- **建筑与室外细节**：增加窗台、窗框、部分空调、屋顶女儿墙、屋顶机房和入口雨棚；调整主楼玻璃立面和西门构件。家属区从整片占位体块改为推演楼排；加入球门球网、篮架、看台、喷泉水柱、低矮绿篱和花坛。
- **画面**：程序化天空、云层、夜空星点、墙面/地面细节，以及批量树冠绘制。步行时缩小阴影范围以改善近处阴影。所有效果在本地生成，无在线贴图依赖。

这是风格化的**校园室外漫游场景**，不是商业游戏级美术成品或完整数字孪生。六处照片参考之外的外观、家属区单楼轮廓和景观布置仍属推演；没有楼内空间、真实地形高差、攀爬、屋顶行走、复杂角色动画或 NPC。跳跃不用于登上建筑；飞行是观察与布置模式。校园原有粗碰撞并未覆盖每个装饰构件。

## 直接体验

Mac 双击 `Start-Campus.command`，或执行 `npm run preview` 后打开 `http://127.0.0.1:4173`。运行需要 Node.js 20.19+（或双击启动时使用 Python 3）；本机已有 Node.js。核心体验不需要连接互联网，不请求在线字体、贴图或音频。参考资料链接需要联网。

`release/西土城四季-2.0.zip` 是独立运行包；解压后双击其中的启动文件。不要直接双击 `dist/index.html`，浏览器需要通过附带的本地服务加载模块。

## 内容与操作

- 51 栋命名建筑，西门、道路、运动场、喷泉、绿地与树木；包含座椅、路灯、自行车和可读标牌。
- 四季独立切换：春季花瓣、夏季树冠、秋季落叶、冬季裸枝与可调薄雪。可关闭动画或仅查看固定主体。
- 日间、黄昏、夜晚；夜晚路灯亮起。可选合成风声、鸟鸣与脚步，默认静音。
- 九处导览停留、地图路线、地点介绍、手记收集与结尾；也可自由探索或从校园手册选择安全起点。
- 本地保存手记进度、季节、日夜和画面设置；支持明信片 PNG 下载。

全景：拖动旋转、滚轮缩放、右键平移。漫游：WASD / 方向键移动、鼠标转向、Shift 加速、空格跳跃、V 切换人称、F 飞行 / 落地、E 阅读、Esc 暂停。若浏览器不允许捕获鼠标，可按住画面拖动转向。触屏：方向按钮移动、拖动画面转向、点按地点提示。系统开启减少动态效果时默认关闭季节动画。

进度保存在浏览器本地，不上传。要恢复，请使用相同浏览器和相同本地端口；5173 的开发预览与 4173 的运行版各自保存。清理网站数据会清除进度；隐私模式或禁用存储时使用本次会话内存，界面会提示。

## 模型与源码

- `public/models/bupt-haidian-base.glb`：固定主体，建筑、道路、场地、树干与枝条、环境设施。
- `public/models/bupt-haidian.glb`：固定主体与默认绿色树冠的静态场景。
- `public/models/colliders.json`：与模型坐标一致的粗碰撞盒。
- `src/campus-data.js`：位置、估计尺寸、类别与资料来源。
- `src/campus-model.js` / `src/campus-life.js`：建筑与环境几何。
- `src/seasons.js`：季节、日夜、薄雪表面与风/飘落效果。
- `src/navigation.js`：避障路线与分步碰撞移动。
- `src/places.js` / `src/save.js`：九处手记、来源、本地保存。
- `src/architecture.js` / `src/campus-landscape.js`：建筑细部与景观、体育设施。
- `src/avatar.js` / `src/creative.js` / `src/world-atmosphere.js`：角色、个人布置、天空与程序化材质。
- `src/audio.js` / `src/minimap.js`：原创合成声音与小地图。

GLB 可导入 Blender、Godot 以及支持 glTF 的引擎。Unity 需 glTF 导入支持。Y 向上、X 向东、负 Z 向北，原点为示意范围中心，单位暂按米。楼宇节点保留名称与精度信息。

GLB 仅保存静态几何。实时四季、光照控制、中文标牌纹理绘制、声音、导航与交互由程序实现，导入引擎时需要接入对应功能。静态模型中的标牌底板不含浏览器绘制的文字贴图。角色、程序化天空/墙面着色和个人布置层不在静态 GLB 中，后者通过单独 JSON 导出。

## 制作与验证

```sh
npm install
npm run dev         # 开发预览，默认 5173
npm run export      # 重新生成两个 GLB 与碰撞数据
npm run check       # 几何、季节隔离、路线、保存与模型重导入
npm run check:world # 新增角色、飞行、布置验证；默认预览端口 5174，可设置 CAMPUS_URL
npm run check:browser  # Chrome 端到端测试，需要开发预览位于 5173
npm run release     # 导出、检查、构建、整理独立运行目录
npm run preview     # 运行 dist，默认 4173
```

浏览器测试覆盖完整九站流程、手记结尾、明信片与模型下载、刷新恢复、四季、零积雪、动画关闭、日夜、音量/画质设置、暂停和触屏移动。路线测试实际按碰撞逻辑走完所有相邻停留点；季节测试比较切换前后主体几何、材质和碰撞的指纹，确保主体没有被更改。基础几何和导出模型通过重新导入验证。

开发测试使用本机 Chrome；移动检查是在浏览器中模拟触屏尺寸与输入，不等同于所有手机实机测试。精细画质依赖设备 GPU，可在设置中选择流畅模式。可复核截图保存在 `artifacts/`。

## 参考精度与创作范围

这是完整可玩的风格化校园漫游作品，**不是测绘模型，也不是逐栋写实复刻**。布局来自校园示意图，不是卫星影像或实测轮廓。校园外部范围暂按约 500 × 750 米换算；建筑高度、占地尺度、道路宽度和不可见背面为估算。现有参考无法证明每栋建筑截至制作日的完整现状。

六处地标参考官方照片：未来学习大楼、图书馆、教三楼、教四楼、科学会堂、西门。其余建筑采用统一的简化立面；家属区采用区域内推演楼排，单楼位置未核实。没有室内场景，不可进入建筑。碰撞采用平地粗盒，不模拟楼梯、物理水体或精细植被碰撞。

树种、花期、准确树木位置、季节色彩、积雪分布与光照是美术预设。小松林依据地图名称保留常绿表现。座椅、路灯、自行车布置、标牌与合成环境声属于原创场景设计，不代表现场实测或实录。薄雪覆盖朝上表面并保留道路可读性；不模拟真实雪深、融雪或铲雪。雪花仅用粗楼高避让。

导览说明区分参考事实和模型表达；九站路线是本作品的游览安排，不是学校官方路线。所有未核实部分均可在固定主体中逐项替换，不影响四季与交互结构。
